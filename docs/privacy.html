Privacy Policy for VeloxMD

Last updated: November 20, 2026 · Developer: Lucas Bonomo · License: MIT

1. Overview

VeloxMD is an open-source, offline-first desktop Markdown viewer. VeloxMD does not collect, store, sell, or transmit personal data, usage analytics, crash reports, or telemetry.

2. Local Files and Preferences

  • Documents: Markdown, .mdc, and plain text files opened in VeloxMD are processed strictly locally on your device and are never uploaded to any remote server.
  • Settings: User preferences (theme, font size, OpenDyslexic toggle, and local keybindings.json / fonts.json files) are stored only on your local machine.

3. Network Access

VeloxMD operates offline by default. Network connections happen only when explicitly triggered by you:

  • Manual Update Check: Selecting Check for updates in the About dialog sends a single read-only HTTPS GET request to the public GitHub Releases API (https://api.github.com/repos/lbonomo/VeloxMD/releases/latest) to check whether a newer release exists. No personal identifiers or telemetry are transmitted by VeloxMD.
  • External Links: Clicking an external link inside a document or the About dialog opens that URL in your system's default web browser.

4. Distribution Platforms

When you download or install VeloxMD via the Microsoft Store or GitHub Releases, those distribution platforms may process download or diagnostic metadata under their own privacy policies.

5. Contact

If you have any questions about this Privacy Policy, please open an issue on GitHub at github.com/lbonomo/VeloxMD/issues .
